## Multiple-writer rows (architecture risks carried into SYSTEM-KNOWN-ISSUES.md)

| Fact | Writers | Why it matters |
|---|---|---|
| Artifact bytes and index records | pdf-tool and platform each implement the layout and the index keys | a change to one grammar silently orphans the other's reads (`filename` incident already happened for the reference shape) |
| `request-artifacts/` index | pdf-tool + platform | same |
| Publishing autonomy | CMS-Agent project record + platform policy module | a tenant can be autonomous on one side and gated on the other with no view showing both |
| Object id of a conductor-published article | CMS-Agent (shell under `run.requestId`, or `publishRequestId`) vs platform sweep assumption (`object_id = requestId`) | the platform request record can point at an object that does not exist (S-06) |
| Producer context | plugin LLM (self-authored), platform-tenant hook (CMS-Agent), nobody for dr-lurie conductor publishes | the producer grain in kugel-data mixes id domains and misses CMS-Agent's own content (S-05) |
