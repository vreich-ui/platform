> A contract is listed only if code on at least one side sends or expects it. "Schema owner" = who may change the shape; "Producer/Consumer" = who sends/receives at runtime. Test coverage names only tests that exercise the *shape crossing the boundary*; unit tests with hand-written fakes are marked `(fake)`. Drift risk is judged from duplicated definitions and the absence of a shared fixture.
