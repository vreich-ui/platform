Terms sorted alphabetically; symbol-leading entries first. "Where it lives" is the file that
*defines* the thing, not every consumer.

Four distinctions cause most of the confusion in this repo, so read these first: **record vs export
vs page** (canonical object in Blobs → derived JSON in git → built HTML); **publish vs release**
(export commit vs deploy); **version vs content_revision** (every write vs body writes only); and
**tenant vs fleet** (one `sites/<client>` + its own Netlify project vs all four, governed by the
parity laws).
