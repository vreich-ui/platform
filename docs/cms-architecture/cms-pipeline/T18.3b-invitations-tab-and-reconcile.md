## Scope
1. **Invitations tab** on `/admin/settings/admins`: rows = pending/expired/revoked invitations (accepted ones live in Members): e-mail, role, invited by, sent N× (last at), expires in (countdown / "expired"), **GoTrue send status** (`sent` ✓ / `already_invited` / `identity_admin_unavailable` with a "How to fix" tooltip: "Enable Identity on this site / re-send from Netlify UI"). Actions: Resend (disabled at cap), Revoke (confirm), Copy invitation link (`/admin/accept?inv=<token>` — only shown once at creation time since we store the hash; after that "link no longer available, resend instead").
2. **Invite dialog** upgrades: role picker with the five tiers filtered by policy; optional message (stored on the invitation; shown on the accept page when the `?inv=` preview is used); domain-not-allowed inline error.
3. **Unmanaged identities** panel (Owner): GoTrue users with no membership (from `unmanaged_identities`), each with *Grant role…* (creates an active membership `source:'netlify_ui'`) and *Delete identity* (typed confirm; calls the T18.4 verb — until T18.4 lands, hide the button behind `capabilities.delete_identity` returned by the verb). Empty state: "Everyone in Netlify Identity has a role here."
4. **AcceptInvite.tsx**: when `?inv=` is present call `invite_preview` (T18.2 makes it return inviter/role/site/message for a valid pending token) and render "**Alex** invited you to **Dr Lurié** as **Editor**"; keep the token-less path unchanged.
5. `users-client.ts`: `listInvitations`, `resendInvitation`, `revokeInvitation`, `unmanagedIdentities`, `grantRole`.
6. Tests: pure logic (expiry countdown formatting, action availability by status/cap) in `admin/logic.test.ts`.

## Deliver
Invitations are visible, fixable and revocable from the workspace; nobody added in the Netlify console is invisible.

## Non-goals
Delete-identity side effects (T18.4), MCP/chat (T18.6).
