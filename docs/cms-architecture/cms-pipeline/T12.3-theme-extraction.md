The fixture `snapshot.v1` (computed styles), `packages/core/lib/registry/theme-tokens.ts` (keys, axes, value grammar), `packages/core/schema/bodies/theme-v1.ts`, `packages/core/server/lib/object-verbs.ts` (`site_apply_theme` dry_run contract). (Paths updated 2026-08-13 for the W11/W14 core relocation.)

## Context

Reduce a captured site's look to the governed token surface: the 10 color roles of `THEME_COLOR_KEYS` (+ optional `dark:*` variants where derivable), the font stacks (`sans`/`serif`/`heading` required; `mono` optional — absent falls back to the Tailwind preflight stack), and the W10 axes — nearest-enum quantization, never raw CSS.

**Totality is now enforced (post-W8.3 hardening):** `site_apply_theme` REJECTS a theme missing any renderer-consumed color key — an incomplete theme would delete keys from `site.brandTokens`. The extractor must therefore emit a COMPLETE color set: any role the snapshot gives no evidence for is filled from `FALLBACK_COLORS` (flagged low-confidence in the swatch report), never omitted.

## Scope — files to create/modify

- ✚ `packages/core/cli/capture/theme.mjs`: cluster the snapshot's computed colors → propose the 10 role assignments (page bg, surface, text tiers, primary/secondary/accent/gold) with a confidence + swatch report; font stacks from computed families quantized to safe stacks (font FILES are code — report unavailable families as gaps, don't invent loading); axis values (radius/shadow/rhythm/container/type scale) by measurement → nearest enum.
- Output: a complete `theme.v1` body (metadata trio prefilled, scope `one_off`) + an HTML swatch/specimen report for human review.
- Integration test: extracted theme validates; `site_apply_theme` dry_run against a fixture site record computes a clean exact-replace op.

## Deliver

From snapshot to a valid, reviewable theme draft in one command.

## Non-goals

- No real applies. No font-file shipping. No value outside the token grammar/enums.
- No `site.brandImagery` writes (W16 C1): the captured site's imagery STYLE (photography/illustration style, generation palette, negative list) belongs to the separate governed `brandImagery` surface, whose only writer is the privileged `set_site_brand_imagery` op — no agent-facing writer exists. Record imagery-style observations in the gap/findings report instead.
