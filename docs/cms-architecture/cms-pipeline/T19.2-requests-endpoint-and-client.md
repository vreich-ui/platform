## Why this model / effort
Endpoint + client is routine; the judgement is in the permission model (team-wide read, Owner/publisher archive) and in retiring the O(N) `listChats` poll without regressing the shell's counters. Opus, high.

## Scope
1. **Function** `packages/core/server/functions/admin-requests.ts` (+ the four site shims are T19.9's job; add the drlurie shim here only if the local dev path needs it — say which you did). Actions: `list` (filters: `status[]`, `kind[]`, `mine`, `archived`, `q`; server-side sort per plan §4.1 attention-first; paged with a cursor), `get` (one request, full doc + attached chat summaries), `archive` / `unarchive` (Owner or publisher), `cancel` (creator or Owner), `mute` / `unmute` (self only; writes the `requests/notify/<person_id>` doc reserved by T19.1).
2. **Permissions** exactly per plan §8. Team-wide read is a deliberate departure from `chat-visibility.ts` — comment it as such at the call site so nobody "fixes" it back.
3. **`list` is one blob GET.** It reads `requests/index.json` and never falls back to an N-read scan; if the index is missing or fails to parse it calls `rebuildIndex` once and says so in the response (`rebuilt: true`), rather than degrading to O(N) silently.
4. **Client** `packages/core/lib/admin/requests-client.ts`: typed wrappers mirroring `chat-client.ts` (bearer token, thrown server message, exported view types), plus `requestPollIntervalFor(status)` — fast while anything is live, slow otherwise.
5. **Shell cutover**: `AdminShell.tsx`'s work-summary effect switches from `listChats` + `fetchInventoryRows` to the request index (keep the pending-review count from `fetchInventoryRows` only if plan §4.1's pills still need it — state which). `work-summary.ts` gains a request-based path with its existing tests kept green. The pills' `href` moves off `/admin/release` to the `/admin/requests` filters, even though that route does not exist until T19.4 — note it in the commit body; a 404 for one row's lifetime is better than shipping the wrong destination twice.
6. **Tests**: endpoint unit tests per action incl. every permission refusal; `list` proven to issue exactly one store `get` for the index; cursor paging; the rebuild-once path.

## Deliver
Every surface can ask "what requests exist and what are they doing" in one cheap call, with the right permissions.

## Non-goals
No UI (T19.4), no sweeper, no notification delivery (T19.6 owns the channels; this row only stores mute state).
