## Context

Wolf's ruling: the AI assist lives in CMS-Agent, not the calling user, and
everything that can be deterministic is deterministic. CMS-Agent already has
the seams: a workflow registry awaiting its second entry, deterministic node
fast-paths that complete with zero model calls, controlled tools for pure code,
and two long-run planes for jobs that outlive a function budget.

## Scope

**Controlled tools (pure code, `toolRegistry.ts`):**
- ✚ `capture.crawl` — creates the pdf-tool `capture` job (T12.8) via the
  project adapter, records jobId; completion is awaited by the LONG-RUN PLANE
  (the conductor job / continuation tick re-drives the node until the poll is
  terminal — do not spin inside one 30s `project.call_tool` window).
- ✚ `capture.map` (heuristic mapping), `capture.theme`, `capture.emit`
  (drafts-only; forbidden-verb set enforced), `capture.score` — each a thin
  invocation of the platform engine's logic against stage artifacts. Every tool
  enforces `resolveProjectCapturePolicy` bounds server-side.

**Workflow (`capture_conductor`, registered via `registerWorkflow`):**
- Deterministic nodes (fast-path flags, model = fallback only): crawl →
  map → theme → emit(dry-run) → emit(live) → score → report.
- **AI nodes — exactly three:** `block_classifier` (judges only the blocks the
  heuristic mapper declined; suggestions re-validated by the deterministic
  builder — an invalid or unregistered type is rejected, never coerced),
  `copy_regenerator` (only when the policy's rights require regeneration),
  `gap_adjudicator` (turns residual gaps into the W10 evidence feed + the run
  report's human summary). Each with tight per-node `modelConfig` budgets.
- The workflow composes the shared publish segment (T15.4 mandate): authority is resolved by `publishingPolicy.autonomyMode` and explicit operator decisions. Terminal report carries what was published and what was withheld.
- Ship path: node literal + `npm run nodes:update` + redeploy, recorded.

## Deliver

`workflow.start_dry_run({workflowId: "capture_conductor", input: {sourceUrl,
targetProjectId}})` + `run_all` drives URL → scored draft clone with model
spend only on the three judgment nodes, itemized per run.

## Non-goals

- No new workspace/deployment (the registry isolates the node set). No custom publish/release path (compose the shared segment per T15.4). No genesis/site-creation (T12.11). No prompt-only "deterministic" nodes — deterministic means code, enforced by the fast-path pattern.
