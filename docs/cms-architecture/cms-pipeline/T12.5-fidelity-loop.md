# T12.5 — Fidelity loop: score, iterate bounded, report against the limits rubric

**Phase 12 · depends_on: T12.4 · mode: auto · model: Opus 4.8 · effort: high**
**Blocks:** T12.6; feeds T10.7.

## Read first

`11-platformization-plan.md` §3.1–§3.2 + the OQ-W12-2 ruling (the ratified fidelity bar), the T12.4 run report format, `scripts/build-diff.mjs` + `scripts/lib/html-normalize.mjs` (the house diff/normalize idiom to imitate for screenshots).

## Context

"A copy within reasonable limits" needs a number and a report, or every run ends in vibes. The loop: build the draft site preview (deploy preview or local build of the landing-zone tenant — each `sites/<client>` is its own Netlify project with its own base-directory build), screenshot the emitted pages at the capture viewports, diff against the target's snapshots, propose bounded improvements (different section config/variant/axis value — data changes only), re-emit, re-score; hard iteration cap.

## Scope — files to create/modify

- ✚ `packages/core/cli/capture/score.mjs`: per-page structural score (mapped-block coverage %, order fidelity) + visual score (normalized screenshot diff per block); aggregate against the OQ-W12-2 rubric — the **ratified default** (coverage ≥ 90%, tokens complete, gaps enumerated — NOT a pixel threshold), which each project may **override** through its contract-declared limits block (read the target project's setting; fall back to the default when unset).
- Iteration: improvement proposals limited to schema-legal data edits via the verbs (variant/axis/config swaps); max N rounds (default 3); every round appended to the run report.
- Final artifacts per run: fidelity report (scores, per-page verdicts, screenshots) + the consolidated palette-gap report → referenced from `design-vocabulary-gaps.md` (the T10.7/OQ-W8 evidence feed, closing the growth loop).

## Deliver

Every capture run ends with a scored, comparable, committed report — and the system's vocabulary backlog gets its evidence automatically.

## Non-goals

- No unbounded iteration. No code/CSS changes to chase pixels. No publishing.

## Acceptance criteria

- Fixture run produces the report end-to-end; scores reproducible across two runs on the same input; gap feed appears in `design-vocabulary-gaps.md`.
- Committed `T12.5: …`; no PR.
