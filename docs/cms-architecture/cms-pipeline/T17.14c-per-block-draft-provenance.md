## Context

`markDraftRegions` marks by **object id**:

```ts
const draftIds = new Set(pendingRows.filter((row) => row.unpublished_changes).map((row) => row.object_id));
… region.classList.toggle('dl-em-draft', Boolean(objectId && draftIds.has(objectId)));
```

An article is one object, so **one unpublished change marks every block in it**
— a dashed outline on all of them and, since T17.6, a `· draft` chip beside
every heading. The PDF shows exactly one.

The data to fix it already exists and is already read: the Pending tray's
`summarizeUnpublished` walks `record.history` backwards to the last `publish`
entry, and `phraseForEntry` pulls `entry.details.op.node_id` /
`entry.details.op.section_id` off each op to say "Text edited in Hook". The
same walk yields the changed **set**. Records are warm — `preloadRecords`
fetches every page object's record on activation and `fillTrayRow` reads the
same cache — so this costs no new request.

## Scope

- **New pure module `packages/core/lib/edit-mode/draft-provenance.ts`:**

  ```ts
  export type ChangedUnits = {
    /** Ops that dirty the object as a whole (create, set_page_meta, set_site_fields, …). */
    wholeObject: boolean;
    nodeIds: Set<string>;
    sectionIds: Set<string>;
    /** False when history was unavailable or unreadable — the caller falls back. */
    resolved: boolean;
  };

  export const changedUnitsSince = (history: readonly HistoryEntry[]): ChangedUnits;
  ```

  Identical loop shape to `summarizeUnpublished`: iterate backwards, stop at
  `publish`, skip `checkout` / `checkin` / `refresh_lock`, treat `create` as
  `wholeObject`. Op → unit mapping: `update_node` / `upsert_node` /
  `remove_node` ⇒ `node_id`; `update_section_data` / `upsert_section` /
  `remove_section` / `move_section` ⇒ `section_id`; `set_page_meta`,
  `set_site_fields`, `set_site_brand_tokens`, every nav op
  (`update_item` / `upsert_group` / `remove_group` / `upsert_action` /
  `remove_action` / `set_nav_meta` / `move_item`), every product and term op
  ⇒ `wholeObject`. An op shape the mapping does not recognise ⇒ `wholeObject`
  (never silently ignored).
  Move or share the `HistoryEntry` type rather than declaring a second one.
- **`markDraftRegions` marks a region iff** its object is pending **and**
  (`wholeObject` **or** its `nodeId` / `sectionId` is in the changed set).
  Read the record from the existing `cachedRecord`; do not add a fetch.
- **Fallbacks, and they must be explicit in the code's comment:**
  `resolved === false` (no history, or nothing recognised) ⇒ mark the whole
  object, i.e. exactly today's behaviour. **The fix can only ever be more
  precise, never wrong in a new way.** A `remove_node` names a block that no
  longer renders and is already handled by `.dl-em-removed`; it contributes
  nothing. Ops an agent performed through MCP land in the same history, so the
  provenance is not canvas-only.
- **R4's footer state pill** (built as a stub by T17.14a) is wired to the same
  source: `Published · {date}` from the record's `published_time`, `Draft ·
  unpublished` (`--dlem-draft`) when the object's
  `PendingObjectRow.unpublished_changes` is true, `Never published` otherwise.
  Object-level, matching the PDF, which shows the article's state and not the
  paragraph's.
- **Do not remove the dashed `.dl-em-draft` outline** — it narrows with the
  chip and keeps its meaning. The chip's gold `draft` badge is already gone
  (retired by T17.14a).
- **Unit tests (`node:test`):** `changedUnitsSince` against fixture histories —
  a node edit after a publish; two node edits; a node edit **before** the last
  publish (must not count); a section edit; a `create` with no publish; a
  `set_page_meta`; an unrecognised op; an empty history (`resolved: false`);
  and a history whose only entries are `checkout`/`checkin` (`resolved: true`,
  nothing changed). Mirror `attention.test.ts`'s style.

## Acceptance criteria

- Against the PDF: an article with one unpublished node change shows the
  `· draft` chip and the dashed outline on **that block only**; every other
  block is clean. Editing a second block adds a second chip; publishing clears
  both.
- A page whose whole-object field changed (`set_page_meta`) still marks the
  whole page — the fallback is not a regression.
- A record with no readable history behaves exactly as it does today.
- `Pending N`, the tray's rows and `summarizeUnpublished`'s phrasing are
  unchanged — the tray and the canvas now demonstrably agree about which unit
  changed, because they read the same walk.
- `17-canvas-ux-plan.md` §7 gains a T17.14c entry in the same commit.
- `npm run check` and `npm test` green. Committed `T17.14c: …`; no PR.
