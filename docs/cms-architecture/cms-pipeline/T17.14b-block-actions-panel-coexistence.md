## Context

T17.14a proved the fold works: one card, one state machine, the chip gone. It
deliberately left four actions and the `content_grid` configuration homeless
so the state-machine diff stayed reviewable. This task gives them their home —
labelled rows in the footer chevron's drawer — and fixes the collision the
chip's removal exposes: `anchorPanel` places the docked panel at
`rect.right + 14`, **the rail's exact slot**, with no rail awareness, so a
panel and a bubble can be painted on top of each other.

## Scope

- **Fill the drawer (R5)**, computed per block, in this order, omitting rows
  that do not apply. Labelled text rows with a leading glyph — **not** an icon
  strip:

  | Row | Condition | Action |
  | --- | --- | --- |
  | `Image…` | the exact `hasImage` predicate the chip used: `region.dataset.cmsNodeKind === 'content'` for nodes, `IMAGE_SECTION_TYPES.has(target.sectionType)` for sections | `openPanel(target, region, 'image')` |
  | `Role & intent…` | article nodes | `openPanel(target, region, 'role')` |
  | `Article settings…` | `content_item` blocks | `openPanel(target, region, 'meta')` |
  | `Ask AI…` | not `isNav`; **interim, deleted by T17.7** | `openPanel(target, region, 'ai')`, carrying the armed selection scope |
  | `Related articles` group | `region.dataset.cmsRelatedAlgorithm` present | the existing algorithm `<select>` + tiles + columns inputs, now with **visible labels** rather than `title` attributes, wired to the **unchanged** `applyRelated` |
  | — hairline + `Delete block` | already built by T17.14a | unchanged |

  `Article settings` is reachable in one gesture for the first time: today
  `'meta'` has no chip button and is only reachable by opening the panel with
  some other tool and then clicking its accordion head.
- **The selection quotation strip** (affordance-model §2, R3): when
  `selectionRegion` is this bubble's block, render a one-line strip above the
  composer — `“…first 60 chars…” ✕` — and scope the interim `Ask AI…` row to
  it. This replaces the chip's `.dl-em-ask.dl-em-sel` highlight, which was the
  only indication a selection was armed. Dismissing the strip clears
  `currentSelectionText` / `selectionRegion`. Design it once, here: **T17.4
  reuses this strip as the span anchor's surface** and must not invent a second
  one.
- **Panel↔rail coexistence** (affordance-model §5.1):
  1. `anchorPanel` becomes rail-aware — `left = railLeftPx ?? (the current
     clamped rect.right + 14 fallback)`, `top = Math.max(RAIL_TOP, rect.top)`,
     width `Math.min(372, RAIL_W)` so the panel never exceeds the column the
     rail already reserved. **In `slide` mode the padding is already applied,
     so nothing on the page moves when the panel opens** — Wolf's no-movement
     ruling satisfied structurally, not by care.
  2. While a panel is open the rail yields: `rail.classList.add('dl-em-rail-yield')`
     hides bubbles (gutter markers unaffected); `closePanel` removes it. The
     affordance state stays `pinned(R)`, so closing the panel restores exactly
     the bubble that was there.
  3. Precedence, highest first: inline edit (occupies the block, not the
     column) > panel > pinned bubble > revealed bubble > ghost bubble. Only one
     of {panel, bubble} is ever painted in the column.
  4. In `sheet` mode (`< 900px`) both are already the bottom sheet: the panel
     wins, the rail stays collapsed.
  5. `morphFromTile`'s source becomes the **drawer row's** rect, falling back
     to the bubble's rect, falling back to no morph. Reduced-motion gating
     unchanged.
