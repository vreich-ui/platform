## Scope
1. `AdminUsers.tsx` → members table columns: avatar+name, e-mail, **role badge**, **status badge** (`invited|active|suspended|removed(hidden by default, toggle)`), source badge (`env` = "Break-glass (env)", `bootstrap`, `invitation`, `netlify_ui`, `mcp`), last seen, row menu: Change role (dialog with the five tiers + one-line description; disabled options when policy forbids), Suspend / Reinstate, Remove (typed-confirm dialog: type the e-mail; explains "keeps history, purge after N days"), Promote to stored Owner (env rows only), View audit (drawer listing `AuditEvent`s for the person via `member_audit` verb — add the verb to `admin-users` if T18.1 didn't: Owner-only, `{email, limit}`).
2. Guards surfaced in UI: cannot act on self (existing), `last_owner` 409 → toast copy "Transfer ownership or add another Owner first", env rows: only Promote.
3. Copy fixes: "will lose all access immediately" → "loses access within an hour (sessions expire) and cannot act from now on"; "You can re-invite them later" only on Remove.
4. Non-owner Admin sees the page read-only (list) — respect `roles` from `useCurrentUser`.
5. `users-client.ts`: `suspend/reinstate/remove/promoteBootstrap/memberAudit`.
6. Tests: `packages/core/admin/logic.test.ts` gets pure-logic tests for role option availability (policy × actor role × target role) — extract that predicate into `logic.ts`.
